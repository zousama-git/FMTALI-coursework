# Power BI Practicals

This repository contains my **Power BI practicals**, covering **Practical 1 through Practical 10**.

Prerequisites:
- Power BI Desktop (recommended: latest stable release).
- Basic familiarity with Excel and working with tabular data.

How to use these files:
- Each practical folder contains a PDF with step-by-step instructions and an assets/ directory with supporting files (images, sample data zips).
- Extract the ZIP files in the assets/ folder before opening them in Power BI Desktop.

Contact / License:
- For questions or corrections, open an issue on this repository.

Each practical documents the work completed during the corresponding session, including the concepts and tasks covered.
